# User-Story -- Inventory management
## Main Menu
The user can choose between three options: add product, check product list and calculate simple stadistics.
## Add product
Ask the user for name, price and quantity; then it adds to main dictionary.
## Check product
Shows every product with name and quantity currently in stock, or 'currenty empty' if there's no info in main dictionary.
## Stadistics
Ask the user if they want to calculate total inventory value or total products registered,
